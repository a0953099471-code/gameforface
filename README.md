# AI 表情闖關遊戲

這是一個純前端瀏覽器遊戲，使用 MediaPipe Face Mesh 進行即時臉部偵測，並透過嘴巴與眼睛表情操控戰鬥。所有功能皆在瀏覽器內執行，可直接部署到 GitHub Pages。

## 專案檔案

- `index.html` - 遊戲入口
- `style.css` - 介面樣式
- `script.js` - 遊戲邏輯與 MediaPipe 偵測

## 遊戲規則

- 玩家透過臉部表情操控技能。
- `ATTACK`：張嘴攻擊 Boss，造成傷害並增加能量。
- `DEFEND`：閉嘴防禦，啟動後可使下一次 Boss 攻擊傷害減半。
- `CHARGE`：睜眼集氣，提升能量值。
- `ULTIMATE`：閉眼發動終極技能，需能量達 100% 才可釋放，造成大量傷害。
- 每次技能觸發後同一技能會有 2 秒冷卻時間。
- 表情必須穩定維持至少 0.8 秒，才會正式執行技能。
- Boss 每 3 秒自動攻擊一次，直到玩家或 Boss 血量歸零。
- 玩家 HP 歸零則遊戲失敗；Boss HP 歸零則遊戲勝利。

## 遊戲玩法

- 張嘴：`ATTACK`
- 閉嘴：`DEFEND`
- 睜眼：`CHARGE`
- 閉眼：`ULTIMATE`

當動作持續超過 0.8 秒後才會觸發，且同一技能會有 2 秒冷卻，避免誤判。

## 功能

- 即時 MediaPipe Face Mesh 臉部關鍵點繪製
- 實時顯示嘴巴開度、眼睛開度、辨識到的動作
- 玩家 HP、Boss HP、能量值、冷卻倒數
- Boss 自動攻擊與遊戲勝利 / 失敗判定

## GitHub Pages 部署

1. 將此專案推送至 GitHub 倉庫。
2. 在 GitHub 倉庫的 `Settings` 中找到 `Pages`。
3. 設定發佈來源為 `main` 分支，資料夾選擇 `/(root)`。
4. 儲存後即可開始部署。
5. 等待 GitHub Pages 發佈完成，點擊提供的網址即可啟動遊戲。

> 注意：此專案不使用 Python、Streamlit、Django、Render 或任何後端服務。全部運算皆在瀏覽器內完成。

## 測試方式

1. 開啟 `index.html`。
2. 允許瀏覽器使用相機權限。
3. 當鏡頭啟動後，確認頁面能即時繪製 Face Mesh 特徵點。
4. 透過張嘴、閉嘴、睜眼、閉眼分別觸發技能。
5. 確認資訊面板會顯示玩家 HP、Boss HP、能量、冷卻與特效文字。
6. 等待 Boss 自動攻擊並驗證勝利 / 失敗結果顯示。
